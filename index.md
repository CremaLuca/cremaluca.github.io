## What I worked on

### A Graph approach to settlement status prediction

> Python + AWS ~ from 03/2022 to 12/2022 ~ In
> [Euronext](https://www.euronext.com/en/csd/milan)

Master's thesis work based on data science.
Extends the prediction model for the settlement status of settlement instructions
with features extracted from modeling the system as a graph.

### [Fantanuoto](https://fantanuoto.it)

> Django + PostgreSQL + AWS ~ from 05/2021 to 08/2025 ~ With **Samuele**

Similar to fantasy football, but for swimming.
Players compete in private "leagues" by choosing a team of swimmers that compete
in national, european, world and olympic competitions.
The score is calculated based on the results of the swimmers and the platform provides
daily and per-competition rankings.

### [OTRI - Open Trading Research Infrastructure](https://github.com/OTRI-Unipd/OTRI)

> Python + Docker + Kubernetes ~ from 04/2020 to 11/2020 ~ With
[Riccardo](https://github.com/RicDeZen)

Group of services and scripts to retrieve, validate and analyze a large quantity of
financial data.
Uses the map-reduce paradigm to process the data in parallel.
Self-hosted on a Kubernetes cluster.

### [Replicated and distributed networks based on SMS communication](https://github.com/Cogno-Marco/network-dictionary)

> Android + Java ~ from 12/2019 to 02/2020 ~ With
> [Marco](https://github.com/Cogno-Marco) and
> [Marco](https://github.com/d-u-d-e)

Java library that implements the peer-to-peer protocol "Kademlia" in replicated or distributed mode on the SMS network.
It allows to write, read and remove a generic data.

### [GloobETF](https://gloobetf.com)

> PHP + jQuery ~ from 05/2019 to 12/2019 ~ With [Federico](https://github.com/colbietech)

Commissioned by a local financial advisor. Website to showcase his activity and platform to track the
investments of his users. It taught me that it's more important to do a deep functional analysis rather
than starting from the code.

### [Nuotobet](https://nuotobet.altervista.org)

Web platform to bet on the results of provincial and regional swimming competitions I used to partecipate in.
First approach to systematic scraping of data about competitions' registrations and results. Restructured
the database a couple of times as I was learning about normalization and relations between tables.


### [Zero](https://play.google.com/store/apps/project-details?id=io.threesoft.Zero)

> Unity3D + C# ~ from 02/2018 to 08/2018 ~ With [Igor](https://github.com/Igor16) and [Oleksandr](https://github.com/OleksandrDemian)

Android game developed with Unity3D. Given a series of numbers, a list of filters and a list of mathematical
operations, the goal is to make all the numbers reach 0 using the operations and the filters in the right
order.

### [Swims](https://play.google.com/store/apps/details?id=com.CremaGames.Swims)

> Unity3D + Javascript ~ from 04/2015 to 06/2015

My first approach to mobile game developement using Unity3D.
A clicker game based on swimming where you have to beat the computer with incremental difficulty.
A later version allows you to compare your results using Google Play Services leaderboards.

### [Rivendilibro](http://rivendilibro.altervista.org/)

> PHP + JQuery ~ from 05/2016 to 06/2016

Online marketplace inspired by <a href='https://subito.it'>subito.it</a> for exchanging used books.
The site provides a list of registered books or you can register new ones.
For each book it lists who is selling it and allow you to get in touch with the user via chat.
